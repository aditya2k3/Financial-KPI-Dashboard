# Power BI dashboard

This folder is meant to hold your **Power BI Desktop** file (`.pbix`). Binary `.pbix` files are not generated by this repo—you build them locally and optionally commit them if your Git workflow allows large files.

## Build steps

1. Install [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
2. **Get Data** → **Text/CSV** → select `../data/cleaned_data.csv`.
3. In **Power Query**, ensure types: `Date` (date), `Region` and `Category` (text), `Revenue`, `Profit`, `Quantity` (decimal/whole number). Add columns if needed: `Year`, `Month`, `YearMonth`.
4. **Close & Apply**.
5. Create visuals aligned with the analysis notebooks:
   - **KPI cards**: Total Revenue, Total Profit, Profit Margin %, YoY growth (use measures).
   - **Line chart**: Revenue by month (`YearMonth` or `Date` hierarchy).
   - **Bar / matrix**: Revenue and margin by Region and Category.
   - **Slicers**: Region, Category, Date range.
6. Save as `powerbi.pbix` in this folder.

## Measures (DAX sketches)

Create measures such as:

- `Total Revenue = SUM(cleaned_data[Revenue])`
- `Profit Margin % = DIVIDE(SUM(cleaned_data[Profit]), SUM(cleaned_data[Revenue]))`
- `MoM Revenue % =` use `PREVIOUSMONTH` on a date table, or compare to prior month in your model.

For a rigorous time intelligence setup, add a **Date table** marked as date table and relate it to `cleaned_data[Date]`.

## Screenshots

Export report pages or use **File → Export** as PDF for stakeholders. For GitHub, save PNG previews under `../images/` (e.g. `dashboard_preview.png`)—the Jupyter notebook `kpi_analysis.ipynb` can also generate a matplotlib composite for the README.
